# BelleStays Paris

BelleStays Paris is a full-stack web application built with Django that allows users to browse accommodation listings in Paris. The goal of the project is to create a modern booking platform inspired by services such as Airbnb, where users can explore properties, view detailed information, and make accommodation bookings.

This project is currently under development.

---

# User Experience (UX)

## Target Audience

BelleStays Paris is designed for:

- Tourists visiting Paris
- Business travellers
- Couples and families
- Anyone looking for short-term accommodation

## User Goals

Users should be able to:

- Browse available properties
- View detailed information about each property
- Navigate easily throughout the website
- Book accommodation

- Responsive Bootstrap layout
